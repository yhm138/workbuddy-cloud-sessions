# 排障手册

排障的顺序是固定的：**先看页脚「数据与诊断」，再看这份表。** 面板把几乎所有的状态都摊在那里——版本、pid、缓存条数、最近调用的参数形状，比猜快得多。

---

## 0. 诊断区怎么读

打开面板 → 拉到**页脚** → 展开「数据与诊断」，会看到类似：

```
页面版本  : 1.11.1
扩展版本  : 1.11.1
宿主通道  : MessagePort · ready
云端直连  : service v1.11.1 · pid 24912 · 3 条缓存 · via port
上次回放  : 0.9s（票据 210 / 握手 120 / 首帧 130 / 回放 380ms） · 42 条
```

| 行 | 正常 | 不正常说明 |
| --- | --- | --- |
| 页面版本 vs 扩展版本 | 两行相同 | 不同 = 宿主缓存了旧文件，**完全退出客户端**再开 |
| 宿主通道 | `MessagePort · ready` | `__ipc` 是兜底通道，能用但慢；`timeout` 见第 2 节 |
| 云端直连 | `service vX · pid …` | `不可用 —— …` 后面就是原因 |
| 上次回放 | 0.5～1.5s | 票据/握手占了大部分 → 网络；回放占大头 → 会话太大 |

> 版本号不一致时，面板顶部也会有一条「页面与扩展版本不一致，重启即可」。

---

## 1. 总表：症状 → 原因 → 处理

| 症状 | 最可能的原因 | 处理 |
| --- | --- | --- |
| 菜单里没有「云端会话」 | 扩展没装到客户端目录 / 没完全退出 | `wbcs deploy` → 托盘退出客户端再开 |
| 「插件加载失败，请检查网络后重新加载」 | ① 握手超时 ② 宿主缓存了旧文件 | 看第 2 节 |
| 正文顶部写「本机快照」 | service 没起来 | 看第 3 节 |
| 「云端直连」显示版本但拉正文报 `NO_TICKET` | 宿主登录态过期 | 客户端里随便打开一个会话 / 重新登录 |
| 某条会话点开空空如也 | 定时任务类会话本来就没正文 / service 不可用 | 看第 4 节 |
| 点「网页版打开」好像没反应 | 浏览器开在后台，宿主不回报成败 | 用「复制链接」兜底 |
| 客户端「融合会话」里同一条是空的 | 小程序 / App 来源，客户端不加载这类历史 | 用网页版，别在客户端里找 |
| `no_token_401`（CLI） | Playwright profile 里的 cookie 过期 | `wbcs login` |
| 安装向导一闪就没 | `runtime\node.exe` 没解出来 | 重新「全部解压」，别拖文件 |
| 安装提示需要管理员权限 | 客户端在 `C:\Program Files` | 右键「以管理员身份运行」 |

## 2. 「插件加载失败」

两种完全不同的原因，先看诊断区的宿主通道一行：

**① `Guest Ready timed out after 10000ms`**
扩展没在 10 秒内完成 `guest-ready` 握手。宿主把 iframe 加载完成后发 `__wb_port_init__` + MessagePort，页面必须在 10 秒内回一条 `wb:boundary:guest-ready`。v1.0.2 之后已修，若还出现，多半是宿主通道被阻塞（先关掉别的扩展试试）。

**② 资源 404 / 页面纯白**
宿主在启动时缓存了扩展目录的文件快照。运行期替换目录后，它仍按旧快照取文件，于是新 `index.html` 引用了不存在的资源。
→ **完全退出客户端**（托盘右键 → 退出）再打开。热更新只对下次启动生效。

---

## 3. 「本机快照」= service 没起来

面板降级了：能读，但读的是上次抓的快照，不是最新。诊断区会写 `云端直连 : 不可用 —— <原因>`。

按可能性排序：

| 原因 | 怎么确认 | 处理 |
| --- | --- | --- |
| 部署目录是旧版本 | 诊断区版本号 / `grep VERSION server/index.cjs` | `wbcs deploy --force`，然后**托盘退出**再开 |
| 客户端不认识 `service` 声明 | `extension.json` 里有 `service` 但宿主忽略 | 客户端版本太老，升级客户端 |
| fork 被拦 | 诊断区显示 `PERMISSION_DENIED` / 空 | 安全软件 / 企业策略；把客户端目录加白名单 |
| service 崩了 | `pid` 一直在变 | 完全退出客户端再开；仍崩则在 issue 里贴诊断区全文 |

**为什么必须重启？** `service` 是客户端**启动时** fork 的。热更新扩展目录只会换文件，不会重启子进程——所以永远是旧版本在跑。

## 4. 会话是空的

先分清三种「空」：

**a. 定时任务类会话** —— 数据本身如此。这类会话只有任务定义和触发记录，没有对话正文。面板会直说「没拉到正文」，别反复重试。

**b. 小程序 / App 来源** —— 历史只存在云端，客户端不加载。面板能回放，但客户端里那条永远是「暂无对话记录」。**这是客户端行为，不是 bug**，扩展也不该去写它的库。

**c. 云端确实有，但没拉下来** —— 用「从云端拉最新正文」重试；或 CLI：

```bash
node bin/wbcs.js fetch --only 2070359399505326080 --force
```

如果报 `NO_TICKET`，是宿主登录态的问题，不是这条会话的问题。

## 5. 抓取类问题（CLI）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `no_token_401` | profile 里的 cookie 过期 | `wbcs login` |
| 弹不出浏览器 | 系统里既没 Chrome 也没 Edge | `npx playwright install chromium` |
| 明明登录过又跳扫码 | 换了浏览器（Chrome ↔ Edge 的 cookie 密钥不同） | 删 `.wbcs/browser.json` 重新选，之后钉死同一个 |
| 抓一半卡住 | 会话太大，空闲超时太短 | `--idle 6000` |
| 抓完条数比网页版少 | 尾部被截断（服务端还在补） | `--force` 重抓，或调大 `--idle` |
| 中文乱码 | Windows 控制台编码 | `chcp 65001`，或用 Windows Terminal |

## 6. 数据在哪、怎么重置

| 内容 | 位置 |
| --- | --- |
| 登录态（Playwright profile） | `.wbcs/profile/` |
| 正文快照 | `.wbcs/sessions.json` |
| 浏览器选择 | `.wbcs/browser.json` |
| 导出的 Markdown | `export/` |
| 面板本地偏好（收藏/主题/搜索历史） | 浏览器 `localStorage`（键前缀 `wbcs.`） |
| 安装包数据目录 | `%LOCALAPPDATA%\wbcs` |

想从零开始：`wbcs uninstall`（会问要不要删数据）→ 重新 `wbcs install`。
只想清缓存但保留登录：删 `sessions.json`，再 `wbcs fetch` 一次。

## 7. 还是不行

提 issue 时请带上：

1. 诊断区整段文本（页脚展开后手动全选复制）
2. 客户端版本 + 扩展版本
3. 复现步骤：哪一条会话、点了哪个按钮、期望什么、实际什么

**不要贴会话正文**，只需要 id 和条数。仓库里所有截图都用示例数据生成，请不要破坏这个约定。

→ [提 issue](https://github.com/yhm138/workbuddy-cloud-sessions/issues/new/choose)
